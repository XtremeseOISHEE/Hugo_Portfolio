**Primary Android developer in a collaborative project · September–November 2025**

Implemented focus mode, productivity analytics, app blocking, task lists, user profiles, gamification, title updates and an AI assistant using Kotlin, Jetpack Compose and MVVM.

The current repository documents Room storage, Firebase and an OpenRouter-backed chat integration. App blocking and usage analytics require Android access settings; system-wide grayscale is a development-device capability.
