## Making reasoning inspectable
**Student Researcher — Explainable Clinical AI · January 2026–present**

I designed the framework, RAG pipeline and multi-hop clinical evidence verification methodology from scratch, using Python and ChromaDB. Each inference is classified as supported, partially supported or unsupported by retrieved evidence.

Preliminary evaluation covers routing, out-of-scope handling, evidence support and reasoning-depth ablation. The Streamlit interface supports cached showcase cases and live analysis. This is a research prototype, not a clinically validated decision tool.

Supervisor: [Dr. Md. Ezharul Islam](https://juniv.edu/teachers/ezharul.islam). A first-author journal manuscript is in preparation.
