**Primary prototype developer · 2026**

Built NASA POWER data processing, a calendar constraint engine, bilingual interfaces and automated checks. Integrated 10,227 daily climate records from 1998–2025.

The prototype checks crop occupancy, irrigation dependence and seasonal calendar margins while making missing evidence visible. It withholds comparative recommendations where outcome evidence is insufficient. Field validation remains outstanding; climate summaries are regional context, not farm measurements.

During development, 31 JavaScript and five Python tests passed. Independent project; not endorsed by NASA.
