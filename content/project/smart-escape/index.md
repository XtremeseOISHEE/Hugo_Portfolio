A Bangla/English practice web app that draws a building’s floor graph and finds the lowest-cost route from a selected location to an open exit. Blocking rooms, junctions or corridors and closing exits triggers route recalculation.

The repository documents a hand-drawn, keyboard-accessible SVG map, Dijkstra routing and a side panel showing the path and cost. This is a software demonstration; it has not been validated for real emergency evacuation.
